# Font Files Required

Please download and place the following font files in the `/public/fonts` directory:

## Plain Font
- Plain-Regular.woff2
- Plain-Regular.woff
- Plain-Bold.woff2
- Plain-Bold.woff
(For headings and titles)

## HelveticaNowDisplay Font
- HelveticaNowDisplay-Regular.woff2
- HelveticaNowDisplay-Regular.woff
- HelveticaNowDisplay-Bold.woff2
- HelveticaNowDisplay-Bold.woff
(For body text and UI elements)

The fonts are already configured in `src/index.css` and will load automatically once placed in this directory.
